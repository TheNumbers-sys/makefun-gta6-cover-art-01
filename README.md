Vice City Cover Studio turns photos from your device into original sunset-soaked, multi-panel cover art. Arrange the panels, tune each photo crop, write your own title and export a PNG. The app runs offline after it is served; photos are never uploaded.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
